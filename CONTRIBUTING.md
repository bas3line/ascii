# Contributing

Thanks for wanting to add to ascii.rest. New pieces are the best contribution, and fixes to existing ones, docs and the site are welcome too.

## Setup

You need Node 23.6 or later, which runs TypeScript files directly, so the scripts need no build step.

```sh
git clone https://github.com/bas3line/ascii
cd ascii
npm install

# the site, to see your piece on a page
cd site
npm install
npm run dev          # builds the library, then http://localhost:4321
```

## How it fits together

- `src/pieces/`: one file a piece. This is where most contributions go.
- `src/mount.ts`: plays a piece in a `<pre>`, or on a `<canvas>` for the coloured scenes.
- `src/ascii.ts`, `src/react.tsx`, `src/astro/Ascii.astro`: the `<ascii-art>` tag, the React component and the Astro component, all built on `mount`.
- `src/pieces/index.ts` and `src/library.ts`: generated by `npm run gen`. Don't edit them by hand.
- `scripts/`: `check.ts` (the contract checker), `gen.ts` (the indexes), `compare.ts` (frame-for-frame comparison against reference files).
- `site/`: [ascii.rest](https://ascii.rest), an Astro site that uses the package like any app would.

## Write a piece

A piece is one TypeScript module with no runtime imports. It exports `meta` and a default function. The function takes the options and returns a `Frame`: `(t, env) => string`, the picture at `t` seconds as exactly `rows` lines of `cols` characters.

```ts
import type { Frame, Meta } from "../types.ts";

export const meta = {
  name: "spinner",
  category: "ui",
  note: "a line turning while something loads",
  cols: 10,
  rows: 1,
  fps: 6,
} satisfies Meta;

export default function spinner(): Frame {
  return (t) => `${"|/-\\"[Math.floor(t * 3) % 4]} loading `;
}
```

A piece with options exports an interface for them and types its meta with it, like [`typewriter.ts`](src/pieces/typewriter.ts):

```ts
export interface TypewriterOptions {
  [key: string]: unknown;
  prefix: string;
  phrases: string[];
}

export const meta = { /* ... */ options: { prefix: "i make ", phrases: ["small tools."] } } satisfies Meta<TypewriterOptions>;

export default function typewriter({ prefix = meta.options.prefix, phrases = meta.options.phrases }: Partial<TypewriterOptions> = {}): Frame {
  // ...
}
```

### The contract

`npm run check` enforces all of this:

- **File**: `src/pieces/<slug>.ts`, the slug in kebab-case.
- **`meta`**:
  - `name`: lowercase.
  - `category`: one of scenes, shapes, space, physics, nature, creatures, objects, generative, effects, ui, data, type, logos.
  - `note`: one lowercase line of up to 72 characters, saying what you see.
  - `cols` and `rows`: up to 80 by 32.
  - `fps`: 0 to 60, 0 for a still.
  - `options`: optional defaults.
  - `clock: true`: only if the picture reads the real time.
- **Exact size**: every frame is exactly `rows` lines of exactly `cols` characters.
- **Characters**: printable ASCII, `·`, `°`, and the box drawing and block elements, U+2500 to U+259F.
- **Deterministic**: the same `t` gives the same frame. Use a seeded PRNG (the pieces use mulberry32 or a hash), never `Math.random`, and `Date` only with `meta.clock`.
- **Self-contained**: `import type` from `../types.ts` is fine, and nothing else. No DOM and no globals: the checker fails a piece that mentions `document`, `window`, `globalThis` and the like, even in a comment.
- **Fast**: under 4 ms a frame on average and 30 ms at worst, on a laptop. Precompute in the outer function; do only what moves in the frame.
- **Light pages**: `env.paper` is true when the text is dark on a light ground. A shaded piece flips its ramp then, so dense characters still mean dark.

A **scene** (`category: "scenes"`) is a coloured picture drawn on a canvas:
- It adds `palette` (up to 64 colours as `#rrggbb`), `ground` (the colour behind it) and `cell: 1` for square cells.
- It may be up to 320 by 120 and may also use `•` and `●`.
- Each frame writes a palette index for every cell into `env.color`, a `Uint8Array` of `cols * rows`, row by row.
- Its budget is 10 ms a frame on average.

A **logo** (`category: "logos"`) is a language's logo, coloured on a canvas with no `ground`, so it sits on the page:
- It adds a `palette` and writes `env.color` like a scene. `env.paper` tells it the page is light, so it can lift colours that would sink into a dark one.
- Without `env.color` it is drawn as text in one ink, in a `<pre>` (`mono` on the tag and the components), and must read that way too.
- Draw it from the logo's own artwork, credit the source in its header, and keep it to the logo: no wordmark unless that is the logo.

### What makes a good piece

The checker only checks the contract; a reviewer reads the frames. A piece is ready when it is:

- **Recognisable** at a glance, with no caption inside the art. Ui, data and type pieces naturally contain text.
- **Crafted**: real shading, a composition centred in its frame, clean silhouettes, deliberate characters. Not noise, and not a rectangle of characters.
- **Alive**: it moves the way its subject would, and loops without a visible jump.
- **A good still at frame 0**: that frame is rendered on the server, and it is all that people who prefer reduced motion see.
- **Proportioned**: a character cell is about twice as tall as it is wide, so circles need correcting.
- **New**: not a reskin of a piece already in the library.

### Check it

```sh
npm run gen                         # add it to the indexes
npm run check -- spinner --show     # the contract, and frames at 0, 1, 2.5 and 5 seconds
npm run typecheck                   # strict TypeScript
```

Then look at it on a page: with `npm run dev` running in `site/`, open `http://localhost:4321/spinner/`.

## Pull requests

- **One piece or one fix a PR.** Branch from `main`; don't commit to it.
- **Before you push**: `npm run typecheck` and `npm run check` must pass, and CI runs the typecheck and the build again.
- **Show it**: paste the frames from `npm run check -- <slug> --show`, or a screenshot of the piece page.
- **Changing an existing piece**: say what you changed and why.
  - If it's a refactor that shouldn't change the picture, prove it: copy the old file into a folder, then run `node scripts/compare.ts <that folder> <slug>`.
- **Match the code around you**: plain names and sparse comments, like [`donut.ts`](src/pieces/donut.ts).
- **License**: by contributing you agree your work is released under the [MIT license](LICENSE).

## Reporting bugs and ideas

Open an issue with one of the templates: a bug report (what you did, what you saw, which browser) or a piece idea. Security problems go through [SECURITY.md](SECURITY.md), not public issues.

Be kind; the [code of conduct](CODE_OF_CONDUCT.md) applies to every issue, pull request and discussion.

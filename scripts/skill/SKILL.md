# ascii.rest

ascii.rest is an npm package, `ascii.rest`, with no dependencies: {{pieces}} animated pieces of ascii art, each one a small TypeScript module, plus banners (any text in block letters) and a kit to make more. Every piece plays only while it is on screen and holds one still frame for readers who prefer reduced motion, so it needs no extra code for either.

## Work in this order

1. **Find where it goes.** Read `package.json` and the files around the spot the user means:
   - `next` → Next.js, `react` → React, `astro` → Astro, `vue`, `svelte` or no framework → the HTML tags.
   - A `README.md` on GitHub → an SVG, since GitHub runs no script.
   - A CLI in Node → `ascii.rest/terminal`.
2. **Pick the piece.** Search [references/pieces.md](references/pieces.md) by category and by what each one shows. Use a name exactly as it is listed there, or as `npx ascii.rest list` prints it. Never make one up: an unknown name draws nothing. For a language, a company or a distro, look under logos, companies and distros first. When nothing fits, make one with the kit (below), or ask.
3. **Add it** the way the target needs (below), with the rules at the end.
4. **Check it.** Run the project's dev server or build and look at the page. For a README, open the SVG's URL. For a terminal, run `npx ascii.rest <name> --seconds 3`.

## Put a piece on a page

Install it for React, Next.js, Astro or a bundler: `npm install ascii.rest`.

**React and Next.js.** `<Ascii>` is already a client component.

```tsx
import { Ascii } from "ascii.rest/react";
import { donut } from "ascii.rest/pieces";

<Ascii piece={donut} />
```

In a server component, pass the name instead of a module: `<Ascii piece="donut" />`. With options: `<Ascii piece={typewriter} options={{ phrases: ["hello"] }} />`.

**Astro.** It renders the first frame on the server, so the page is whole before any script runs.

```astro
---
import Ascii from "ascii.rest/astro";
---
<Ascii piece="donut" />
```

**Plain HTML, no build step.** The script loads each piece from ascii.rest on demand.

```html
<script type="module" src="https://ascii.rest/ascii.js"></script>
<ascii-art piece="donut"></ascii-art>
```

**Vue, Svelte or anything else with a bundler.** Import the tags once, in code that runs in the browser, then write them in templates as in HTML. Tell the framework that `ascii-art` and `ascii-banner` are custom elements (in Vue, `compilerOptions.isCustomElement`).

```ts
import "ascii.rest/element";
```

**Any element, by hand.** `mount()` plays a piece in a `<pre>` (text pieces) or a `<canvas>` (canvas pieces) and returns a function that stops it. Call it when the element goes away.

```ts
import { mount } from "ascii.rest";
import { donut } from "ascii.rest/pieces";

const stop = mount(document.querySelector<HTMLPreElement>("#art")!, donut);
```

## Write text in block letters

```tsx
import { Banner } from "ascii.rest/react";        // Astro: import Banner from "ascii.rest/astro/banner"

<Banner text="hello" />
<Banner text="hello" font="slim" shadow="rounded" effect="type" />
<Banner text="hello" color={["#f97316", "#f778ba"]} />
```

In HTML, `font`, `shadow`, `fill`, `effect`, `speed`, `color` (colours joined by commas), `pixel` and `gap` are attributes: `<ascii-banner text="hello" font="slim" color="#f97316,#f778ba"></ascii-banner>`. Every other option goes in the `options` attribute as JSON, or it is ignored: `<ascii-banner text="hello" options='{"max":40,"pad":1}'></ascii-banner>`. The options: `font` (`block`, `slim`, `tall`, `bold`, `round`, `wide`, `mixed`, `italic`), `shadow` (`double`, `single`, `heavy`, `rounded`, `ascii`, `none`), `color` (one `#rrggbb` or a list for a fade), `effect` (`glint`, `type`, `still`), `speed`, `fill`, `pad`, `max`. All of them, with what each takes: [references/docs/banners.md](references/docs/banners.md). A banner draws only the characters its font has: letters, digits, spaces and `. , ! ? ' : - + = / _`.

## Put one in a GitHub README

GitHub runs no script, so use the animated SVGs, a light and a dark one:

```html
<picture>
  <source media="(prefers-color-scheme: dark)" srcset="https://ascii.rest/svg/rust.dark.svg">
  <img alt="rust" src="https://ascii.rest/svg/rust.svg" width="240">
</picture>
```

Only the logos, companies and distros have hosted SVGs: `https://ascii.rest/svg/<name>.svg` and `.dark.svg`. Any other piece has no URL and would be a broken image: make its SVG with `svg()` from `ascii.rest/svg`, write both files into the repo and point the README at them ([references/docs/svg.md](references/docs/svg.md)). A banner is `https://ascii.rest/banner/<text>.svg` and `.dark.svg`, with the text URL-encoded (a space is `%20`, a comma `%2C`), up to 20 characters. Its look goes in the query, the same on both URLs: `?color=f97316,f778ba&tagline=making%20things&art=rust&effect=type`. Colours in a URL have no `#`. Every key: [references/docs/readme.md](references/docs/readme.md). The user can also make one by clicking at https://ascii.rest/banner/.

## Play one in a terminal

- Try any piece with nothing installed: `npx ascii.rest donut`. `npx ascii.rest banner "hello"` prints a banner.
- A splash screen for a Node CLI: `import { play } from "ascii.rest/terminal"`, then `await play("donut", { seconds: 2 })`.
- A banner in a CLI's output: `await banner("my-cli")` from the same module.
- Piped or in CI, `play()` draws nothing and `banner()` prints the banner still, with no colour, so logs get no escape codes.

Details in [references/docs/terminal.md](references/docs/terminal.md).

## Turn an image or a logo into ascii

- With no code: https://ascii.rest/make/ turns an image into a piece, with an embed snippet, a README snippet and the piece's source to copy.
- In code: `fromImage()` from `ascii.rest/kit` takes any image in a browser, and PNG in Node.

See [references/docs/images.md](references/docs/images.md).

## Make a new piece

Use the kit, `ascii.rest/kit`, and start with a recipe: one call by name, with options in words.

```ts
import { sea, spinning, torus, stars, pulsing, heart, gauge } from "ascii.rest/kit";

sea({ palette: "ocean" });
spinning(torus());
stars().behind(pulsing(heart())).named("love");
gauge({ label: "cpu", value: "64%" });
```

What the kit makes is a normal piece: pass it to `<Ascii piece={...}>`, `mount()`, `svg()` or `play()`. Go down to `field()`, `scene()`, `particles()`, `picture()` or `piece()` only when no recipe fits. `npx ascii.rest play file.ts --watch` plays a file's default export in the terminal while you edit it. Start at [references/docs/kit.md](references/docs/kit.md).

## When something is wrong

- **Nothing shows.** Check the name against [references/pieces.md](references/pieces.md). With the HTML tags, check the closing tag is there and the script is a `type="module"`. Look in the console: a banner with an option it can't take warns why.
- **The rows are spaced apart.** A text piece in React needs `line-height: 1.2; margin: 0` on its `<pre>`; the HTML tags and Astro set them already.
- **The wrong size.** A text piece takes `font-size`; a canvas piece takes `width` (in React, in `style`, not a class), never `height`.
- **It starts again on every render.** A piece made during render, like `banner("hello")` in JSX, is new each time: make it outside the component or in `useMemo`, or use `<Banner>`.
- **It doesn't move.** The reader's system asks for reduced motion, so it holds one frame, as it should. It also pauses off screen.

More in [references/docs/faq.md](references/docs/faq.md).
